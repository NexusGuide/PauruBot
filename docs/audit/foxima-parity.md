# Foxima parity tracker

Features of the Foxima reference bot (read-only clone) compared with PauruBot. As with ClockBot,
Foxima's features are added beside ours; nothing PauruBot already does is changed or removed.
Status: ✅ we have it · 🟡 partly · ❌ missing.

## Messaging and broadcasts

| Foxima | PauruBot | Note |
| --- | --- | --- |
| Broadcast text or media to all / buyers / non-buyers | ✅ | ours also: active, inactive, resellers, language, opt-out |
| Forward broadcast | ✅ | |
| Pin, with an unpin time | ✅ | web form now offers it too |
| Unpin every pinned broadcast | ✅ | |
| Buttons under a broadcast that open the bot (buy, trial, help, referral, top up, start) | ✅ added | section buttons beside our link buttons (bot and web) |
| Buyers of one panel | ✅ added | bot and web |
| People who have not used the bot for N days | ✅ added | bot and web; ours kept "no service use for 7 days" |
| Live status, cancel | ✅ | ours also pause / resume / schedule / test send |
| Final report to the admin who sent it | ✅ added | sent / failed / blocked / deleted / skipped |
| Message one user: text or picture | ✅ added | any media in the bot |
| "User may reply" button on a staff message | ✅ added | opens the customer's support tickets; bot and web |
