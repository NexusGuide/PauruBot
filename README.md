# PauruBot

ربات فروش اشتراک VPN در تلگرام، با پنل مدیریت تحت وب، مینی‌اپ تلگرام و پشتیبانی هم‌زمان از چند پنل.

[English](README.en.md)

## چه کاری انجام می‌دهد

- **فروش خودکار:** مشتری در ربات یا مینی‌اپ پلن را انتخاب می‌کند و پرداخت را انجام می‌دهد. سرویس روی پنل ساخته می‌شود و لینک، QR و کارت تصویری سرویس برایش فرستاده می‌شود.
- **کیف پول با دفتر حساب دوطرفه:** هر شارژ، خرید، برگشت و پاداش یک سند ثبت‌شده است. تکرار یک درخواست هیچ‌وقت دوبار پول جابه‌جا نمی‌کند.
- **پنل مدیریت فارسی و انگلیسی:** شامل مشتری‌ها، سرویس‌ها، سفارش‌ها، پرداخت‌ها، تیکت‌ها، پلن‌ها، تخفیف‌ها، گزارش فروش، قیف فروش، پشتیبان‌گیری و به‌روزرسانی. برای هر صفحه راهنمای داخلی دارد.
- **نماینده‌ها:** گروه و تخفیف، صورت‌حساب پیش‌پرداخت یا بر اساس مصرف و ساعتی، سقف خرید، نمایندهٔ سطح دو، خرید چندتایی، و ربات اختصاصی نماینده با توکن خودش.
- **رشد فروش:** زیرمجموعه‌گیری، سطح‌های وفاداری، گردونهٔ شانس، قرعه‌کشی، کد تخفیف و هدیه، عضویت اجباری کانال، تست رایگان، خرید از وب بدون ثبت‌نام، و پاسخ خودکار تلگرام بیزینس.
- **عملیات:** صف کارهای ماندگار، پایش پنل‌ها و هشدار، همگام‌سازی مصرف، هشدار پایان حجم و زمان، اطلاع قطع دستگاه، پشتیبان رمزگذاری‌شدهٔ روزانه، و به‌روزرسانی و بازگشت از داخل پنل.

فهرست کامل قابلیت‌ها و وضعیت هر کدام در [docs/FEATURES.md](docs/FEATURES.md) است.

## پنل‌های پشتیبانی‌شده

| نوع | پنل‌ها |
|---|---|
| اشتراکی (V2Ray/Xray) | پاسارگارد، مرزبان، مرزنشین، رمناویو، ربکا، گارد (v1 و v2)، هیدیفای، 3x-ui (Sanaei) |
| وایرگارد | WGDashboard (فایل .conf و QR)، WG-Mate |
| نام کاربری و رمز | یوزرمنیجر میکروتیک (RouterOS 7)، IBSng (ابتدایی: ساخت، خواندن مصرف، حذف) |

## روش‌های پرداخت

- کارت به کارت با بررسی رسید، تشخیص رسید تکراری و تأیید خودکار اختیاری
- زرین‌پال، آقای پرداخت، تترا۹۸، واریزا، آبان، بلوپال، کیوب‌پی و اطلس‌پی
- ترون از طریق ترونادو، NowPayments و Plisio
- ارز دیجیتال مستقیم (USDT-TRC20، TRX، TON) با تشخیص خودکار واریز
- استارز تلگرام

هیچ پرداختی فقط با اطلاعاتی که به کال‌بک می‌رسد شارژ نمی‌شود. یا از خود درگاه استعلام می‌شود، یا امضای HMAC کال‌بک بررسی می‌شود. اگر مبلغ کمتری برسد، پرداخت برای بررسی همکار نگه داشته می‌شود.

## نصب

پیش‌نیاز: یک سرور اوبونتو یا دبیان با دسترسی root و دست‌کم ۱ گیگ رم، یک دامنه که به آن سرور اشاره کند، و توکن ربات از @BotFather.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/NexusGuide/PauruBot/main/install.sh)
```

نصب‌کننده Docker را نصب می‌کند، فایل `.env` را می‌سازد و کلیدها را تولید می‌کند. بعد سرویس‌ها را بالا می‌آورد و یک لینک یک‌بارمصرف برای ساختن حساب مالک در پنل مدیریت می‌دهد. نصب بدون پرسش هم ممکن است:

```bash
install.sh install --domain bot.example.com --token 123:ABC --owner 123456789
```

اگر پورت ۴۴۳ سرور را سرویس دیگری گرفته است (مثلاً xray روی سرور پنل VPN)، پورت HTTPS را عوض کنید:

```bash
install.sh install --domain bot.example.com --token 123:ABC --owner 123456789 --https-port 8443
```

در این حالت پنل و مینی‌اپ روی `https://bot.example.com:8443` سرو می‌شوند و `PUBLIC_URL` هم خودکار همین می‌شود. پورت ۸۰ باید آزاد بماند؛ Caddy گواهی TLS را از همان‌جا می‌گیرد. پورت ۸۴۴۳ یکی از پورت‌های مورد قبول تلگرام برای وب‌هوک هم است.

پس از نصب، دستور `pauru` (بدون ورودی) منوی مدیریت سرور را باز می‌کند: وضعیت، لاگ‌ها، راه‌اندازی دوباره، پشتیبان، بازگردانی، به‌روزرسانی و بازگشت به نسخهٔ قبل.

### انتخاب کانال و نسخه

نصب تعاملی (بدون `--channel`) کانال را می‌پرسد: `stable`، `beta` یا `dev`. برای نصب مستقیم روی کد `main` از کانال beta استفاده کنید:

```bash
install.sh install --domain bot.example.com --token 123:ABC --owner 123456789 --channel beta
```

مدیریت بعدی از ترمینال:

```bash
pauru channels                  # کانال فعلی و نسخهٔ هر کانال
pauru versions                  # نسخه‌های منتشرشدهٔ stable
pauru switch beta               # رفتن به beta (main/edge)
pauru switch stable             # برگشت به stable
pauru switch --version v0.5.7   # نصب یک نسخهٔ مشخص
```

`switch` قبل از تغییر، پشتیبان می‌گیرد. اگر از beta/dev به stable برگردید و پایگاه داده جدیدتر باشد، همان پشتیبان پیش از کانال آزمایشی به‌طور خودکار پیشنهاد/بازیابی می‌شود؛ در غیر این صورت باید تا انتشار stable جدید صبر کنید یا پشتیبان قدیمی‌تر را برگردانید.

### تنظیمات مهم `.env`

| کلید | توضیح |
|---|---|
| `DOMAIN` و `PUBLIC_URL` | دامنهٔ سرور. گواهی TLS را Caddy خودکار می‌گیرد. |
| `BOT_TOKEN` | توکن ربات اصلی |
| `OWNER_TELEGRAM_IDS` | آیدی عددی تلگرام مالک‌ها، با ویرگول جدا |
| `MASTER_KEY` | رمزگذاری رمز پنل‌ها و کلیدهای درگاه. از دست دادنش یعنی خوانده نشدن آن‌ها. |
| `BACKUP_PASSPHRASE` | رمز فایل‌های پشتیبان. جایی بیرون از سرور نگه دارید. |
| `HTTPS_PORT` | پورت HTTPS پنل. پیش‌فرض 443؛ برای نصب کنار پنل‌های VPN مثلاً 8443. |
| `BOT_MODE` | `polling` یا `webhook` |

بقیهٔ تنظیمات، از جمله پرداخت، پلن‌ها، متن‌ها و منوی ربات، از داخل پنل مدیریت انجام می‌شود. فهرست کامل تنظیمات در [docs/reference/settings.md](docs/reference/settings.md) است.

## بعد از نصب

1. از لینک راه‌اندازی، حساب مالک را بسازید.
2. در «پنل‌ها» پنل VPN را اضافه کنید و اتصال را آزمایش کنید.
3. در «پلن‌ها» لوکیشن و پلن بسازید.
4. در «تنظیمات» یک روش پرداخت را روشن کنید.
5. خودتان یک خرید آزمایشی انجام دهید.

راهنمای کامل هر بخش داخل پنل مدیریت، زیر «راهنما»، هست.

## ساختار

یک برنامهٔ پایتون با سه فرایند روی PostgreSQL و Redis کار می‌کند:

- `api`: پنل مدیریت، مینی‌اپ، کال‌بک درگاه‌ها و وب‌هوک‌ها
- `bot`: ربات اصلی و ربات‌های اختصاصی نماینده‌ها
- `worker`: صف کارها و کارهای زمان‌بندی‌شده

جزئیات در [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)، دسترسی نقش‌ها در [docs/AUTHZ.md](docs/AUTHZ.md) و مدل تهدید در [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md) است.

| بخش | فناوری |
|---|---|
| سرور | Python 3.12، aiogram 3، FastAPI، SQLAlchemy 2، Alembic |
| داده | PostgreSQL 16، Redis |
| رابط کاربری | React 19، TypeScript، Vite، Tailwind 4 |
| اجرا | Docker Compose، Caddy |

## توسعه

```bash
pip install -e .[dev]
bash scripts/check.sh          # ruff، mypy و تست‌ها (PostgreSQL و Redis محلی لازم است)
cd frontend && npm ci && npm run build
```

مستندات مرجع (تنظیمات، API، نقش‌ها و دستورها) از روی کد ساخته می‌شوند:

```bash
python -m paurubot.ops.docgen
```
